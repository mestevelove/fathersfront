# Fathers Front SEO Toolkit

This internal toolkit adapts the five-part DataForSEO workflow described in
the video [Opus 5 Just Destroyed a 1.9 Billion Dollar SEO Tool](https://youtu.be/pGEil0yuW1A)
for `fathersfront.com`.

## One-time setup

1. Create a DataForSEO account.
2. Add `https://mcp.dataforseo.com/mcp` as a custom connector in the AI client
   used to run these audits.
3. Approve the connector and allow its tools for the project.
4. Open this repository as the Fathers Front project so the analysis can use
   the actual routes, copy, metadata, and structured data as context.

Do not store DataForSEO credentials, API keys, or exported customer data in
this repository.

## Run order

Before conventional SEO work, use the guided search-market discovery program:

- [`search-market-discovery.md`](./search-market-discovery.md)
- [`category-brief-template.md`](./category-brief-template.md)
- [`question-bank-template.csv`](./question-bank-template.csv)

This discovery program is for determining what the market is asking, what it
is actually searching for, and which questions Fathers Front can answer with
real authority. The five audits below come after that foundation is established.

1. [`01-site-explorer.md`](./01-site-explorer.md)
2. [`02-keyword-research.md`](./02-keyword-research.md)
3. [`03-content-gap.md`](./03-content-gap.md)
4. [`04-technical-audit.md`](./04-technical-audit.md)
5. [`05-ai-visibility.md`](./05-ai-visibility.md)

Run one file at a time. Treat recommendations as research, not automatic
authorization to change production. Confirm keyword strategy before rewriting
copy, titles, routes, or navigation.

## Shared constraints

- Primary domain: `https://fathersfront.com`
- Market: United States
- Language: English
- Brand pillars: Leadership, Lifestyle, Law, and Love
- Core offers: Stolen Sons, Family Lawfare, Brotherhood, Advisory, and speaking
- Preserve the distinction between general education/coaching and legal advice
- Do not recommend publishing thin, duplicative, or generic AI-written pages
- Separate measured facts from hypotheses and label missing data clearly

## Reporting

Every report should begin with:

- Date and data source
- Geographic and language settings
- Pages or competitors examined
- Material data limitations
- Three highest-impact actions

Prefer a short prioritized backlog over a long unranked list.
