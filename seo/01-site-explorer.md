# Site Explorer

Use the connected DataForSEO tools to analyze `fathersfront.com` in the United
States, English-language market.

Return:

1. Every organic keyword currently associated with the domain, grouped by
   ranking page and search intent.
2. Current position, search volume, estimated traffic, keyword difficulty or
   competition signal, and SERP features when available.
3. Pages with declining visibility, striking-distance keywords in positions
   4-20, and pages whose query intent does not match their title or copy.
4. Cannibalization risks where multiple Fathers Front URLs compete for the same
   intent.
5. The three pages to improve first, with evidence and the smallest useful
   change for each page.

Do not propose new copy yet. End with a prioritized table containing URL,
opportunity, evidence, recommended action, effort, and expected impact.
