# Technical SEO Audit

Audit `https://fathersfront.com` with connected DataForSEO tools and the local
project source. Prioritize issues that can materially affect crawling,
indexing, rendering, performance, or search presentation.

Check:

- HTTP status, redirects, canonical URLs, robots directives, and sitemap state
- Titles, descriptions, headings, Open Graph, Twitter cards, and duplicate data
- Structured data validity and opportunities that match visible page content
- Internal links, orphaned pages, broken links, and inconsistent route targets
- Mobile rendering, Core Web Vitals signals, image dimensions, formats, and
  loading behavior
- Indexable production pages versus portal, test, preview, and internal assets

For every finding, provide the affected URL or source file, observed evidence,
severity, ranking impact, and exact recommended fix. Do not inflate the report
with harmless style preferences or generic best-practice warnings.
